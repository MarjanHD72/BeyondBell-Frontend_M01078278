# BeyondBell Frontend

BeyondBell is a web application for discovering and booking after-school classes and activities for children.

This repository contains the Vue.js frontend for the BeyondBell Full Stack Development project.

## Main Features

- Display classes and activities from MongoDB
- Search lessons by keyword
- Sort lessons by subject, location, price and spaces
- Filter lessons by teacher
- Display teacher profiles and their lessons
- Add lessons to the shopping cart
- Remove lessons from the cart
- Display cart quantities and total price
- User registration
- User login and logout
- Checkout validation
- Create orders
- Update remaining lesson spaces
- Order confirmation
- Printable receipt
- Responsive navigation and mobile menu

## Running the Project Locally

Install the dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build the production version:

```bash
npm run build
```

## Deployment

The frontend is deployed using GitHub Pages.

A GitHub Actions workflow automatically builds and deploys the project whenever changes are pushed to the `main` branch.
